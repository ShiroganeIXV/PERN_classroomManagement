# PERN_classroomManagement

## Backend URL and Arcjet configuration

Set `BETTER_AUTH_URL` to the backend's public origin (for example, `https://classroom-api.up.railway.app`) and `FRONTEND_URL` to the frontend origin. `BETTER_AUTH_URL` is the URL Better Auth uses for callbacks; do not set it to the frontend URL. On Railway, `RAILWAY_PUBLIC_DOMAIN` is used as a fallback and is served over HTTPS. Production startup fails if neither URL is available, rather than silently using localhost.

For Railway, configure `BETTER_AUTH_URL`, `FRONTEND_URL`, `DATABASE_URL`, `BETTER_AUTH_SECRET`, and `ARCJET_KEY` in the backend service's variables. Set `NODE_ENV=production` and `ARCJET_ENV=production`; the backend also normalizes existing `development` or `test` values for `NODE_ENV`, `ARCJET_ENV`, and `MODE` to `production` as soon as its environment bootstrap runs. Arcjet's `127.0.0.1` fallback warning is expected during local development, where there may be no public client IP. Do not trust or accept a client-supplied IP header to hide that warning.

On Railway, leave the backend `PORT` variable managed by Railway. The server listens on `PORT` when set and uses `8000` only as a fallback; do not force `8000` in the deployed service. For the frontend service, set `VITE_BACKEND_BASE_URL` to the backend's public URL **including `/api`**, for example `https://classroom-api.up.railway.app/api`. The frontend Dockerfile exposes this as a build argument, and Vite embeds it in the static build, so set it before building and redeploy the frontend after changing it. `BETTER_AUTH_URL` and `FRONTEND_URL` are origins without `/api`.

For local development, set `BETTER_AUTH_URL=http://localhost:8000`, `FRONTEND_URL` to the local frontend origin, and `VITE_BACKEND_BASE_URL=http://localhost:8000/api`. Copy `frontend_classroom/.env.example` to `frontend_classroom/.env` to provide the frontend value. An existing `PORT` in your shell takes precedence over the backend `.env` value; either remove it for that shell or set it to `8000` there. In PowerShell, run `Remove-Item Env:PORT -ErrorAction SilentlyContinue` to clear it, or `$env:PORT = "8000"` to choose the local port explicitly. Arcjet may use `127.0.0.1` locally when no public IP is available.
